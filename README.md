# 文件整理助手

一个给 Windows 用的单文件小程序：扫描硬盘或文件夹，显示完整的文件夹树和各类文件占用的空间，然后在界面里重命名、新建文件夹、把散落在各处的文件归类移动。

## 下载

在 Windows 电脑上打开 [Releases 页面](https://github.com/missicelove/file-organizer/releases/latest)，下载 `FileOrganizer.exe`（可以改名为“文件整理助手.exe”）。

## 怎么用

1. 双击运行下载的 exe（不需要安装）。
   - 如果出现“Windows 已保护你的电脑”，点 **更多信息 → 仍要运行**（程序没有数字签名，所以会有这个提示）。
2. 会弹出一个黑色窗口，浏览器随后自动打开操作界面。**使用期间不要关闭黑色窗口**，关掉它程序就退出了。
3. 在界面里选择一个磁盘（如 `D:\`）或文件夹，点“开始扫描”。

## 界面

| 区域 | 作用 |
|---|---|
| 左侧：文件夹树 | 每个文件夹后面是它（含所有子文件夹）的总大小，下面的细条表示占上级文件夹的比例。可以按大小或名称排序。 |
| 中间：文件列表 | 当前文件夹的内容，图片和视频显示缩略图。右上角可切换“列表 / 缩略图”视图。切换到“含所有子文件夹”后，会把所有深层文件夹里的文件平铺列出来，并显示“所在位置”。 |
| 右侧：类型统计 | 当前文件夹下各类文件（图片、视频、文档、压缩包……）的数量和大小，点开可以看到具体格式（.jpg、.pdf……）。 |
| 右下：最近新建的文件夹 | 用本程序新建的文件夹会自动出现在这里（程序重启后仍保留），把文件拖到上面即可移动进去。也可以在左侧文件夹上右键“添加到最近文件夹”。 |

## 常用操作

- **找出某类文件**：在右侧统计中点“列出这些文件”，所有子文件夹里的该类文件会集中显示在列表中。
- **一键归类**：在右侧统计中点“归类到文件夹…”，选择（或新建）一个目标文件夹，即可把这一类文件全部移过去。
- **移动**：选中文件后点“移动到…”，或者直接把文件**拖到**左侧文件夹树、上方路径、列表中的文件夹或右下方“最近新建的文件夹”上。
- **右键归类**：在文件上右键，菜单里直接列出最近新建的几个文件夹，点一下就移过去。
- **重命名**：选中后按 `F2`（和资源管理器一样，只选中文件名、保留扩展名）。
- **批量重命名**：选中多个文件后点“批量重命名”，可用 `{name}`（原名）和 `{n}`（序号）组合新名字，也可以查找替换，改名前有预览。
- **新建文件夹**：工具栏按钮，或在左侧树上右键“新建子文件夹”。
- **撤销**：顶部“撤销”按钮或 `Ctrl+Z`，可以一步步撤回之前的操作。
- **删除**：右键“删除”、工具栏“删除”按钮或 `Delete` 键。文件会**移到 Windows 回收站**，可以在回收站中还原（删除不在本程序的“撤销”范围内）。

多选：`Ctrl+点击` 逐个选，`Shift+点击` 连续选，`Ctrl+A` 全选。其他快捷键：`Enter` 打开，`Backspace` 返回上级，`Delete` 删除，`Ctrl+Shift+N` 新建文件夹。

缩略图：JPG、PNG、GIF、BMP、WebP、TIFF 由程序自己生成（相机照片优先使用照片里内嵌的小图，并按拍摄方向自动转正）；视频、PDF、HEIC、PSD 等使用 Windows 系统自带的缩略图（与资源管理器相同，需要系统装有对应的解码器）。

## 安全措施

- 删除只会把文件**移到回收站**，删除前会弹窗确认。U 盘、网络驱动器没有回收站，程序会拒绝在这些位置删除，以免文件无法找回。
- 移动时遇到同名文件会自动改名（如“报告 (1).docx”）或跳过，**绝不覆盖**。
- 不允许在 Windows 系统文件夹、Program Files、ProgramData、AppData 中操作。
- 所有操作（包括删除）都会写入日志：`%AppData%\文件整理助手\操作日志.txt`，里面记录了每个文件的原位置和新位置。
- 程序只在本机（127.0.0.1）提供界面，并带有随机访问令牌，其他网站或电脑无法操作你的文件。

## 开发

```sh
./build.sh          # 运行测试并生成 dist/文件整理助手.exe
go run . -webdir web -no-browser -port 17853 -token dev -trashdir /tmp/假回收站   # 在本机调试（界面文件从磁盘读取，删除的文件移到指定目录）
```

- 后端：Go（`tree.go` 扫描与文件夹树，`ops.go` 移动/重命名/撤销，`server.go` 接口），Windows 专用代码在 `platform_windows.go`。
- 前端：`web/` 目录，编译时嵌入 exe。
- `.github/workflows/windows.yml` 可在 GitHub 的 Windows 环境中运行全部测试并构建。
- 图标与版本信息：`winres/`，修改后在该目录运行 `go-winres make --in winres.json --out ../rsrc` 重新生成 `rsrc_windows_amd64.syso`。
